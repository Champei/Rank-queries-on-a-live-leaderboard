# D4 Rotation metadata and selection

Author: Herin Patel

For a left rotation at `x` with right child `y`, subtree `B=y.left` moves to `x.right`, and `x` becomes `y.left`. The in-order sequence remains `A,x,B,y,C`. After changing links, recompute `x.size=1+size(A)+size(B)` and then `y.size=1+size(x)+size(C)`. Recompute heights in the same bottom-up order. The right rotation is symmetric; a double rotation is two such single rotations, so the argument applies twice. This explains why updating only the new root is insufficient.

For select, let `L=size(node.left)`. Position `L+1` is the node itself. If `k <= L`, descend left; otherwise descend right with `k'=k-L-1`. Each step discards an entire subtree and preserves the target position within the remaining subtree. An AVL has height `O(log n)`, so select takes `O(log n)`.

The integrated AVL audit validates strict pair order, height, balance factor, and subtree size at every node. The application audit also checks the hash and Fenwick counts. The differential harness invokes these audits periodically, or after each operation while reducing a failure. It compares sizes, sampled ranks and selections, periodic position ranges, and all final positions and ranks against a sorted array.

## Independent reference and edge cases

The reference inserts into a vector using its own comparator: score descending, then ID ascending. It does not call the AVL ordering function. For a player's score `s`, a linear scan counts entries with scores strictly greater than `s`; adding one gives competition rank. Selection indexes the sorted vector at `k-1`, while an inclusive range copies `[first-1, min(last,n))`. These simple operations provide a separate implementation against which the optimized structures can be checked.

Targeted cases cover empty state, missing IDs, invalid positions and ranges, negative IDs, ties, repeated revisions, and deletion back to empty. Score-split cases place thresholds below all scores, through a tied score, and above all scores. Each partition is compared with a separately built reference, then merged and checked against the original sequence. The consumed input objects must be empty and pass their audits.

Missing-ID removals are attempted independently on the application and reference, and their exception outcomes must agree. A shared exception handler would skip the second call when the first throws and could conceal a mismatch. Failure reduction deletes chunks while preserving a failing replay; it produces a reduced counterexample, not necessarily a globally smallest one.
