# D6: Predicted and measured costs

**Author:** Sarthak Pandey (250001063)

**Project statement (D6):** Cost models for rank and select in A and B, and for split and join against rebuild, written before measuring.

**Definitions.** Let `n` be live players, `U` allowed score coordinates, `m` players in a merged league, and `k` returned range entries. These are asymptotic operation-count models, not fitted wall-clock predictions.

**Prediction recorded before measurement.** The model was committed in [0f3543f](https://github.com/Champei/Rank-queries-on-a-live-leaderboard/commit/0f3543f) on 2026-11-15. AVL rank and selection descend at most AVL height, hence `T_A(n) = a0 + a1 log2(n)`. Fenwick rank is a prefix sum and selection tests one power-of-two block per bit, hence `T_B(U) = b0 + b1 log2(U)`. AVL split uses joined path pieces and costs `O(log n)`; internal ordered join costs `O(|h1-h2|+1)`. Public join also validates boundary ordering in `O(log n)`. Fenwick division and combination rebuild score counts in `O(n log U)`. Application-level split also rebuilds hashes and Fenwick counts; overlapping league merge inserts `m` entries individually. Coefficients `a0, a1, b0, b1` were left unspecified before timing.

**Method.** `bench/benchmark.cpp` used seed 253, five trials per point, and `n = 1,000, 10,000, 100,000, 1,000,000` on 2026-11-21 with MSYS2 GCC 16.2.0 (`-O2`). The raw file `results/raw/full.csv` contains all trials, sample standard deviations, and means. `bench/plot.cpp` generated the four figures in `results/figures/`. The test machine had an Intel Core Ultra 5 125H and Windows build 10.0.26300; RAM/cache specifications were not accessible to the benchmark account.

| Five-trial mean, us/op | n=1,000 | n=1,000,000 |
|---|---:|---:|
| AVL rank | 0.100 | 2.069 |
| Fenwick rank | 0.098 | 0.640 |
| AVL select entry | 0.100 | 2.329 |
| Fenwick select score | 0.026 | 1.070 |
| AVL score split | 0.704 | 2.564 |
| Fenwick split rebuild | 101.740 | 186,554 |
| AVL ordered join | 0.097 | 0.200 |
| Fenwick join rebuild | 80.560 | 164,618 |

**Comparison.** The query curves rise more slowly than rebuild work, as predicted. Fenwick rank and score selection are faster at one million players, but Fenwick selection returns a score rather than a player ID. AVL score split is under four times its 1,000-player time; rebuilding both Fenwick partitions is over one thousand times its 1,000-player time. Ordered AVL join remains small because the tested halves have similar heights; the model depends on their height *difference*, not simply on total `n`. These isolated measurements do not represent complete application split/merge. At one million players the split-rebuild sample standard deviation was 29,688 us against a 186,554 us mean, so exact ratios are noisy. The measured growth exceeds a constant-coefficient logarithmic latency curve for rank/select; without profiler counters, no cache explanation is claimed.
